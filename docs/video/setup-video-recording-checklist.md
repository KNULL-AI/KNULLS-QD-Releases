# Setup Video Recording Checklist (Draft)

## Before Recording

- Close apps with notifications.
- Hide any private tabs.
- Prepare a demo-safe activation key.
- Prepare demo-safe proxy/account data.
- Confirm latest app release is installed.
- Set display scale to 100 percent if possible.
- Set recorder to 1920x1080, 30 FPS.

## Recording Flow

1. Show latest public release page and download flow.
2. Show app launch and activation.
3. Show Proxy Pool add/check flow.
4. Show Accounts add flow.
5. Show Profiles create flow.
6. Show Task Groups create flow.
7. Show Sessions test launch.
8. Show Discord Monitor setup basics.
9. Show optional IMAP in Settings.
10. Show config export backup.

## On-Screen Hygiene

- Do not expose real keys or credentials.
- Blur or mask sensitive fields if needed.
- Keep cursor movement smooth and deliberate.
- Pause briefly after each major step.

## Captioning

- Base captions on setup-video-captions.srt.
- Keep captions under 2 lines where possible.
- Ensure each caption remains visible long enough to read.

## Export

- Export master video as 1080p MP4.
- Keep a separate version with burned-in captions.
- Keep an upload version with external SRT file.

## Upload Pack

- Final video file
- setup-video-captions.srt
- Thumbnail image
- Title + description text
